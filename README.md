# Лабораторная работа №5 — Программирование

Консольное приложение для интерактивного управления коллекцией объектов `HumanBeing`. Коллекция загружается из JSON-файла и поддерживает добавление, изменение, удаление, сортировку и фильтрацию элементов.

**Курс:** 2-й семестр, весна.  
**Коллекция:** `java.util.Vector<HumanBeing>`.  
**Вариант:** 175.

## Возможности

- Работа с коллекцией через команды в консоли.
- Загрузка объектов из JSON при запуске.
- Сохранение коллекции командой `save`.
- Сортировка объектов через `Comparable` по полю `impactSpeed`.
- Поиск по имени и сравнение автомобилей по полю `name`.
- Выполнение команд из файлов со скриптами и обнаружение рекурсивного вызова скриптов.
- Проверка пользовательского ввода.

## Требования задания

- Использовать `Vector`, реализовать естественный порядок объектов и ограничения полей.
- Передавать имя JSON-файла аргументом командной строки и загружать коллекцию при запуске.
- Читать данные с помощью `Scanner`, записывать с помощью `FileWriter`.
- Документировать все классы в формате Javadoc.
- Обрабатывать некорректный ввод и ошибки работы с файлами, включая отсутствие прав доступа.
- Простые аргументы вводить в строке команды, составные объекты — по одному полю в строку с приглашениями.
- Для перечислений показывать доступные константы; при неверном вводе повторять запрос поля.
- Пустую строку использовать для `null`; автоматически генерируемые поля не запрашивать у пользователя.

## Модель данных по условию

| Поле | Тип и ограничения |
| --- | --- |
| `id` | `int`, больше 0, уникальный, генерируется автоматически |
| `name` | `String`, не `null`, не пустая строка |
| `coordinates` | `Coordinates`, не `null` |
| `creationDate` | `LocalDate`, не `null`, генерируется автоматически |
| `realHero` | `boolean` |
| `hasToothpick` | `Boolean`, не `null` |
| `impactSpeed` | `long`, больше −117 |
| `weaponType` | `WeaponType`, не `null` |
| `mood` | `Mood`, не `null` |
| `car` | `Car`, допускает `null` |
| `coordinates.x` | `Double`, не `null`, не больше 155 |
| `coordinates.y` | `Integer`, не `null`, больше −383 |
| `car.name` | `String`, не `null` |
| `car.cool` | `Boolean`, не `null` |

`WeaponType`: `HAMMER`, `AXE`, `PISTOL`, `RIFLE`, `KNIFE`.  
`Mood`: `SORROW`, `CALM`, `RAGE`.

### Особенности текущей реализации

В коде модель отличается от приведённого условия: `creationDate` имеет тип `LocalDateTime`, координаты — `int x` и `Long y`, а `impactSpeed` — `Integer` с возможностью `null`. Поле `mood` также допускает `null`; ограничение `x ≤ 155` в классе `Coordinates` не задано.

Коллекция читается через `FileReader` и Gson. Команда `save` записывает её в `collection.json` в рабочем каталоге, даже если при запуске указан другой входной файл. Эти особенности следует учитывать при проверке соответствия заданию.

## Команды

| Команда | Действие |
| --- | --- |
| `help` | Справка по командам |
| `info` | Тип коллекции, дата инициализации и количество элементов |
| `show` | Вывести все элементы |
| `add {element}` | Добавить объект |
| `update id {element}` | Обновить объект с указанным идентификатором |
| `remove_by_id id` | Удалить объект по идентификатору |
| `clear` | Очистить коллекцию |
| `save` | Сохранить коллекцию в JSON |
| `execute_script file_name` | Выполнить команды из файла |
| `exit` | Завершить программу без сохранения |
| `remove_at index` | Удалить элемент по индексу, начиная с 0 |
| `remove_greater {element}` | Удалить элементы, превышающие заданный в естественном порядке |
| `sort` | Отсортировать коллекцию в естественном порядке |
| `count_greater_than_car car` | Посчитать элементы с автомобилем, превышающим заданный |
| `filter_contains_name name` | Найти элементы с подстрокой в имени |
| `filter_starts_with_name name` | Найти элементы с заданным началом имени |

`{element}` обозначает составной объект. Для интерактивного ввода выполните `add` или `update id` и следуйте приглашениям программы. Идентификатор и дата создания назначаются автоматически.

## Сборка и запуск

Нужны JDK 21 и Maven 3.

```bash
git clone https://github.com/AlexPer777/lab_5.git lab5_java
cd lab5_java
mvn clean package
java -jar target/lab5_java-1.0-SNAPSHOT.jar collection.json
```

При запуске из другого каталога укажите путь к входному JSON-файлу. Для сохранения требуется право записи в рабочий каталог.

## Использование

1. Запустите приложение с файлом коллекции.
2. Выполните `help`, `info` или `show`.
3. Используйте `add` для добавления объекта и следуйте приглашениям.
4. Сохраните изменения командой `save`.
5. Завершите приложение командой `exit`.

Примеры команд:

```text
show
filter_contains_name Alex
filter_starts_with_name A
sort
execute_script script.txt
save
exit
```
